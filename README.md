# BeehiveWebsite

Beehive Associates is a modern consulting website built with React, TypeScript, and Vite. The site includes a multi-step consultation flow, secure API submission handling, SEO-oriented content, and a polished, mobile-friendly experience.

## Highlights

- Responsive marketing website for Beehive Associates
- Multi-step consultation form with premium custom inputs
- Secure frontend-to-backend submission flow via Supabase Edge Function
- SEO-ready structure with schema and metadata support
- Performance-oriented Vite build configuration for broad browser compatibility

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Supabase Edge Functions
- Lucide icons

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
